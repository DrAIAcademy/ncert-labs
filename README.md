# Dr AI Academy Website

One-page static website for Dr AI Academy, ready for GitHub Pages.

## Files

- `index.html` - Main website page
- `style.css` - Website design and responsive styling
- `CNAME` - Custom domain file for GitHub Pages

## Deploy on GitHub Pages

1. Create a new GitHub repository.
2. Upload these files to the repository root.
3. Go to Settings > Pages.
4. Select source: Deploy from a branch.
5. Select branch: `main` and folder: `/root`.
6. Save.

## Custom domain

Edit the `CNAME` file and replace the domain with your final domain or subdomain.
